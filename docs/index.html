Grayzen

Per-app grayscale for Android.

Turns the screen gray for the apps you choose and brings color back when you leave them. No root, no tracking, no network.

Download APK

What it does

Per-app grayscale

Choose the apps that turn gray. Everything else stays colorful.

Auto-snooze

Pauses the service for apps that don't work with accessibility.

Daily limits

Use Android usage access to set daily time limits.

Private by design

Sees only the focused app's package name. No screen content, no internet.

Open source

See source code

Install

  1. Download the latest APK from Releases and install it. Android 8.0+.
  2. From a computer with ADB, grant the secure setting: 
    adb shell pm grant io.github.ernvk23.grayzen android.permission.WRITE_SECURE_SETTINGS
  3. Open Grayzen and enable its accessibility service in Settings → Accessibility.

Turn Grayzen off before uninstalling, or the screen may stay gray until you disable the service in Accessibility.
